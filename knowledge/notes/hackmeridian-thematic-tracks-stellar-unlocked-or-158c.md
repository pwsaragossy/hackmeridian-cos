# HackMeridian thematic tracks: Stellar Unlocked or Stellar Composed, optional for Scale

The portal track text Pedro copied on 2026-10-25 lists two thematic tracks. Stellar Unlocked means the project gets something new out of Stellar's core protocol features: native asset issuance, the DEX and path payments, ZK host functions (Poseidon, BN254), and contract features such as SAC trustlines. Stellar Composed means the project combines two or more ecosystem tools or live projects (smart wallets, anchors, oracles, private payments, agent wallets, cross-chain bridges) into something none of them does alone. Its idea list includes custody and wallet solutions and "plug into a live project" such as escrow or an anchor.

The same text says Genesis and Scale projects "can also enter" one of these tracks, while the build page says thematic tracks do not apply to Scale ([[hackmeridian-2026-rules-and-submission-requirement-5868]]). Either way the track is optional for Scale and is not one of the seven scored criteria; Scale is scored on Ecosystem Alignment instead ([[hackmeridian-rubric-7-criteria-weights-scored-50e2]]). Pedro chose Stellar Unlocked on 2026-10-24 ([[hackmeridian-scale-intake-as-submitted-the-7fb5]]) and wrote next to it "we can change" on 2026-10-25, so the choice is still open. A custody contract that only uses Soroban fits Unlocked; if the build also plugs into an anchor or another live project for the USD leg, Composed becomes the closer fit.
