# How infrastructure products explain themselves to a lay executive on one screen: 7 transferable patterns (dated 2026-10-25)

Seven patterns seen on 2026-10-25 (page summaries by a small model, not my own eyes; swift.com blocked). (1) Flexport: a map plus ONE sample shipment as dated stops (origin, port, port, warehouse), and counters like "766 shipments, 4 exceptions". (2) project44: every claim is a number plus one customer-context line, no tech words. (3) Stellar.org: each idea gets a one-line analogy ("one shared record instead of each bank's private books") and a three-column icon row (Issue, Move, Deploy). (4) Chainlink: flow of real-world sources, then checkers, then one agreed value. (5) Twilio: the code sample sits in its own section, a few lines, in the visitor's language, ending with the result printed. (6) Plaid/Stripe hero: the word "one API" and a row of logos carry the message; no code in the hero. (7) SWIFT gpi: "track a payment like a parcel", one 36-character reference per payment, status per hop; but the tracker is bank-only, so the lesson is the reference-number idea, not openness. Not verified: any Stripe globe or API snippet (the fetch showed none); Stellar "visual ideas" in the summary were the summarizer's suggestions, not the page's. [INFERENCE] The shared pattern: one concrete object followed through a few stops, analogies in one line, code last and short. Related: [[iata-one-record-is-a-live-e27f]].
