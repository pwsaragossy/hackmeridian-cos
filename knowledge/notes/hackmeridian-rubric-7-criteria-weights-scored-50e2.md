# HackMeridian rubric: 7 criteria, weights, scored 1-5

The HackMeridian build page lists seven criteria and says each is scored 1 to 5 (not 1 to 10): Ecosystem Alignment (Scale; Track Alignment for Genesis) 20, User Value and Problem 20, Technical Execution 15, Innovation 15, Hackathon Progress 10, Market and Ecosystem Potential 10, Product Design and UX 10. They sum to 100. The page also gives a priority order Adoption, Discovery, Continuation without defining the words. For Scale the home page separately lists what is judged: milestone completion against the pre-event intake, SCF eligibility, production readiness, ecosystem impact. The portal tracks PDF has no weights; it only lists requirements. Fetched 2026-10-25 with WebFetch (summarised by a small model, so re-read the page once logged in).
