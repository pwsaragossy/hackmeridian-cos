# HackMeridian 2026 — submission requirements

Source: hackmeridian.com, portal tracks page and event rules, pasted by Pedro on 2026-10-25. Rules and eligibility: RULES.md.

## Requirements for every project

- Public GitHub repository with the project source code.
- README: summary, problem, setup, installation, environment variables, demo instructions.
- Architecture overview: how Stellar is used — assets, contract IDs, anchors, wallets, integrations, APIs.
- Working live demo or video walkthrough. User-facing apps also need a **public live URL**;
  developer tools / infrastructure may use a technical demonstration.
- Evidence of an onchain transaction on testnet or mainnet.

## Submission integrity (disqualifiers in bold)

- Show progress during the event; make the starting point and the new work clear in README and demo.
- **Undisclosed prior work is a disqualification.** Using an existing codebase is fine if declared.
- **AI attribution is required**: note where AI meaningfully generated code or assets.
- Submit: repository link; **demo video 2–4 minutes, YouTube or Vimeo**; **pitch deck as PDF, PPTX,
  PPT or HTML, up to 20 MiB**.
- Conduct: no harassment, cheating, plagiarism or misrepresentation.
